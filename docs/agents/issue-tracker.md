# Issue tracker

- Tracker: GitHub Issues in `maxvyshniakov/mastack`.
- Commands: `gh issue list`, `gh issue view <n>`, `gh issue create`, `gh issue comment <n>`, `gh issue close <n>`.
- Labels: `bug`, `enhancement`.
- Reconciliation: end merge or release commits with `Closes #N` / `Fixes #N` on its own line (which `bin/check` allows). Close an issue only once its completed scope is on `main`; never leave completed work open.
- Language: English.
